What kind of game is Marsfall?

Marsfall is a single-player real-time strategy game with direct control of your friendly units. You can manage an army from above, take control of a soldier or vehicle, and return to strategy while the same battle continues.

What is included in the campaign?

The campaign uses fifty reproducible terrain and layout variants built around seventeen mission families, including escort, defense, resource races, infiltration, Last Stand, and multi-phase finales. Campaign progress unlocks maps for skirmish play.

Can I play against other people?

The current game is single-player. Its configurable skirmishes support one to five AI rivals and allow both same-faction and mixed-faction battles.

What platform is the game for?

The current build is for Windows PC. The portable package includes the game engine and can be run without an installer. Keep the supplied executable and game data together.
